# Survivor 2 v1.0.9

- New Gun, World, System and In-game settings cards. One controller owns the menu pointer and contact dot.
- Direct gun choices, Crosshair, five laser options and a paired right-stick shortcut.
- Wider view Off, On and Fade, with HUD sizing in On and Fade for supported gameplay overlays.
- First Start chooses the solo gun hand. Native weapon preparation is required and reuses a valid cache.
- The existing World size default and saved values are preserved. Native operator settings use Namco Service.

The original World cartridge and NAOMI BIOS are required. The Quest test build was accepted on hardware. PCVR rendering was checked in the simulator.
